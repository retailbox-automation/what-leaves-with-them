# honest-memory

Agent memory on FalkorDB that checks every write before it becomes a fact.

Built for **Graph Hacks: Context for AI Agents** (FalkorDB × WeMakeDevs, Oct 15–18, 2026), tracks **02 Agent Memory and Coordination** and **03 Company Brain**.

> Work in progress. The hackathon window opened 2026-10-14 18:31 UTC; all code in this repository was written after that moment (see `git log --reverse`).

## Idea

An agent memory fails worst when it confidently repeats a stale fact or accepts one that was never true. Every write here goes through a write gate before it reaches the graph:

- a fact with no source is rejected, with a receipt;
- a fact that contradicts the current one closes the old edge (`invalid_at`) with a receipt, so history stays queryable;
- personal or disallowed data is rejected, with a receipt.

Every answer comes with the graph path back to its source.
